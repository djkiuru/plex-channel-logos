# plex-channel-logos

Channel logo images for Plex Live TV (xTeVe). These files are referenced directly via
`https://raw.githubusercontent.com/djkiuru/plex-channel-logos/main/logos/<file>` so that
every Plex client (not just the server) can load them.

Images are network/channel logos mirrored from public sources (mostly tv-logo/tv-logos).
